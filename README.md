# How to Run Java Project
Install Java Development Kit (JDK) on your computer. You can download the JDK from the Oracle website or any other reliable source.
Suppose I have the source code ( Main.java ) inside This PC > Documents folder. I can simply go there through my file explorer.
Go to that folder using 'cd' command.
Now, Run this command inside command Prompt:-
        1. javac Main.java  ;Then press enter.
        2. Then java Main ; Then press enter .
Your, Java Project is run.
# Note:
Closing cmd also close the Java Project.
